# Siaga Bencana Quiz Game

Aplikasi game edukasi mitigasi bencana alam untuk siswa SMA yang dibuat dengan HTML, CSS, dan JavaScript.

## Fitur
- Quiz mitigasi bencana berdasarkan kelas 10, 11, dan 12 SMA
- Timer setiap soal
- Skor dinamis dengan bonus waktu
- Streak / combo jawaban benar
- Best score dan best streak disimpan lokal di browser
- Unduh laporan hasil `.txt`
- Unduh sertifikat sederhana
- Tampilan modern dan responsif

## Cara menjalankan
1. Buka file `index.html` di browser.
2. Atau gunakan Live Server dari VS Code.

## Struktur file
- `index.html` – layout utama
- `styles.css` – desain modern
- `app.js` – logika game dan soal
